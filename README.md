# 🌃 Malioboro After Dark — Yogyakarta

Website promosi wisata yang memperkenalkan keindahan dan daya tarik kawasan Malioboro, Yogyakarta, khususnya suasana malam hari. Website ini dirancang dengan tampilan modern, interaktif, dan responsif untuk memberikan pengalaman menjelajahi destinasi wisata secara digital.

## ✨ Fitur Utama

- 🏠 **Beranda** — Tampilan utama dengan desain menarik dan informasi wisata.
- 📖 **Tentang Malioboro** — Pengenalan sejarah, suasana, dan daya tarik Malioboro.
- 🛍️ **Pengalaman Wisata** — Informasi aktivitas belanja, kuliner, fotografi, dan budaya.
- 📸 **Galeri Foto** — Koleksi foto untuk menampilkan keindahan Malioboro.
- 🎬 **Video Wisata** — Video untuk mengenalkan suasana dan pengalaman berwisata.
- 📍 **Destinasi Terdekat** — Informasi tempat wisata di sekitar Malioboro.
- ❓ **FAQ** — Informasi untuk menjawab pertanyaan pengunjung.
- 📱 **Desain Responsif** — Tampilan yang menyesuaikan berbagai ukuran layar.
- 🎨 **Antarmuka Modern** — Perpaduan warna, tipografi, dan animasi untuk pengalaman pengguna yang menarik.

## 🚀 Cara Menjalankan

1. Clone repository ini:

   ```bash
   git clone https://github.com/univmajalengka/2514101006.git
   ```

2. Masuk ke folder project:

   ```bash
   cd 2514101006
   ```

3. Jika menggunakan XAMPP, letakkan folder project di dalam direktori `htdocs`.

4. Jalankan Apache melalui XAMPP Control Panel.

5. Buka browser dan akses:

   ```text
   http://localhost/wisata_web/
   ```
